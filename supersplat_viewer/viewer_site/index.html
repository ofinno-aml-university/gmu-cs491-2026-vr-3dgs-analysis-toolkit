3DGS scenes

Pick a scene to open it in the SuperSplat viewer. Only the scene you open is loaded; opening another one replaces it.

Adding scenes: drop a .ply (or .compressed.ply, .sog) into the 3DGS_scenes folder on the computer that runs the server, then press Reload list. A .txt with the same name (lines Title:, Author:, License:, Source:) becomes the caption.

Apple headsets and phones: Safari does not let you click past the certificate warning the way the Quest browser does. Open the certificate page once from the plain http:// address (port 3080), install the certificate as described there, and the https address then opens normally.

SOG option: the raw PLY is always the default. Make SOG copy asks the computer running the server to write a compact, lossy .sog copy of that PLY into 3DGS_scenes_converted (seconds to a minute); it then shows up here as an extra Open SOG button. The same for every scene at once: node convert_scenes_to_sog.mjs on that computer.
